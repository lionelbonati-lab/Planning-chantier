Planning à bulles — maquette v3

Clique une case vide pour ajouter une bulle. Clique une bulle pour la sélectionner, double clic (ou entrée) pour l'ouvrir. Glisse une bulle pour la déplacer, tire ses bords pour l'étendre.

Maquette isolée, v3 — rien ici n'est enregistré sur ton vrai planning. Retour sur ce que tu as signalé :
  • Sélection rapide par clic droit/double-tap + tirer — reprend le même geste "ligne × colonne" que l'ajout, mais pour COCHER d'un coup toutes les bulles déjà présentes sur la zone (mode "Sélection", surlignage bleu). On peut ensuite la glisser comme une bulle seule (déplacer/copier), la glisser sur le bouton rouge, ou appuyer sur ce bouton — toujours avec confirmation avant de supprimer.
  • Défiler en mode "Sélection" — un simple glisser sur le fond d'une case fait maintenant défiler le planning normalement (avant, il fallait poser le doigt sur une tâche).
  • Menu Déplacer/Copier au tactile — sans touche Maj, un glisser sur tablette propose ce choix juste après le geste, à l'endroit du doigt (bulle seule ou groupe coché). Le bouton "Copie" a donc été retiré, devenu inutile.
  • Case interdite en orange — le jaune ressemblait trop aux notes ; le dépôt refusé pendant un glisser est maintenant orange.
  • Formulaire d'édition : plus de texte pré-sélectionné — ouvrir une bulle ne sélectionne plus tout son texte, qui ouvrait le clavier tactile par-dessus la fenêtre sur tablette.

Général

Réglages d'affichage du planning.

Chantiers

Couleur utilisée dans la grille et les formulaires.

Statuts

Statuts disponibles pour les tâches des intervenants.

Personnel

L'équipe interne (Lionel, Mathis…).

Intervenants

Les intervenants (Armature / Béton, etc.) — leurs tâches ont un champ Statut.

Entrée rapide

Ces entrées apparaissent dans le menu "Ajouter" de la personne ou de l'intervenant auquel elles sont assignées — Personnel pour tout le personnel interne, ou un intervenant précis.

Nouveau formulaire

Le nom du formulaire + le nom de chaque champ rempli forment le texte de la tâche, dans l'ordre — comme pour Béton ("Béton murs - 50m³ - C301"). Pour une entrée de type Tâche, Chantier et Statut sont aussi proposés automatiquement (pas pour une Absence). Sans aucun champ, l'entrée s'ajoute directement en un clic, sans formulaire (comme Congé/Vacances).

Fériés

Choisis une catégorie ci-dessous puis clique les dates à colorer (reclic = efface). "Calculer les fériés" ajoute automatiquement les jours fériés fixes de l'année et les ponts qui en dépendent — vacances et jours compensés restent à poser toi-même.

Semaines grisées, dates qui n'existent pas (ex. 30/31 février) en noir et non cliquables. La pastille de couleur d'une catégorie s'édite en cliquant dessus.
