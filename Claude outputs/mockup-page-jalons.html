Détails d'implémentation prévus (pas encore codés) :
— Chantier cliquable dans le bandeau ouvre la même petite liste de chantiers que dans une fiche tâche (même correctif de taille que celui livré aujourd'hui).
— Flèches Début/Fin : jour ouvré précédent/suivant, sans les boutons A/P (jours entiers uniquement).
— Cliquer sur une date ouvre aussi le calendrier natif, comme dans les autres formulaires.
— Case « important » conservée dans le bandeau (drapeau) : le champ existe déjà côté serveur pour les jalons, gardée par cohérence — à retirer si tu n'en as pas l'usage ici.
— Enregistrement : même endpoint serveur que les jalons de la grille (aucun changement backend), donc un jalon créé ici apparaît aussi dans « Planning à bulles » dès que tu navigues sur les semaines concernées.
